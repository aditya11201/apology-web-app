# Code of conduct

This project welcomes respectful participation from everyone who contributes through issues, pull requests, discussions, reviews, or project communication.

## Expected participation

- Be respectful, constructive, and considerate.
- Focus feedback on the work and explain disagreements without personal attacks.
- Assume good intent while addressing impact.
- Respect privacy and do not publish personal information.

## Unacceptable behavior

Unacceptable behavior includes harassment, discrimination, threats, intimidation, hate speech, sexualized conduct, unwanted contact, doxxing, deliberate disruption, and sharing private information without consent.

## Reporting

Report concerns privately to the repository maintainers through the repository’s available contact channel. Include what happened, where it happened, when it happened, and any relevant context. Do not post sensitive details in a public issue or discussion.

## Enforcement

Maintainers may remove content, limit participation, or restrict access when behavior violates this code or disrupts a safe project space. Enforcement applies to repository activity and project spaces where maintainers represent the project.
